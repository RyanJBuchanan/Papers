Presets

“Symmetric” sets matching hemispheres. “Circle” removes all radial peaks.

Model assumptions

Planar, regular, embedded loop. Mechanical energy density is ε̂ = 1 + βκ̂²/2; the adopted gravitational source weight is βκ̂², motivated by adding the model’s axial-stress proxy to ε̂. This is a quasi-static phenomenological source, not a complete relativistic stress-energy calculation. The asymmetric profile is a snapshot, not an asserted equilibrium.

Exploratory numerical tool for the model in “Geometric Asymmetry and Gravitational Fields of Closed Elastic Loops.” It evaluates instantaneous loop snapshots; it does not solve the gradient-flow equation. Results describe the specified curvature-weighted quasi-static source model only, not predictions for a physical graviton or a complete relativistic string source.
